Input Overlay

Show recent keyboard presses and mouse clicks over the game.

Input privacy: while this addon is on, it listens for keyboard and mouse buttons system-wide and displays their names on screen. This includes typing in other apps. Inputs are not saved or sent to the internet. Switch the addon off in Settings → Addons to stop listening.
